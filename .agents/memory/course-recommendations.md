---
name: Course recommendations
description: MaydanGo course suggestions must keep member learning signals inside the app.
---

Course suggestions may be ranked inside MaydanGo from the member's saved courses and enrollments, with a clear reason shown for each suggestion. Do not send learning activity or preferences to an external AI service unless the user explicitly changes this decision.

**Why:** The user chose to keep recommendation data in MaydanGo.

**How to apply:** Use first-party course metadata and member-owned signals for recommendations; explain the ranking and do not describe deterministic matching as externally AI-generated.
